# mech_keyboards
DIY mechanical keyboards open source mostly with C due to restrictions using json.
layer made to suit gaming Throne and liberty.
supposed to work with ANSI regardles of system language intput. Same for the norwegian nordic layout.
Using RP2040 elite_pi controller so need to add "-e CONVERT_TO=elite_pi" when compiling.
Using QMK_MSYS for win10.
